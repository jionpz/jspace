# 批量 inbox 整理 — 技术设计

## 架构与边界

- **批量逻辑在 skill 层**(`skills/asset-ingest/SKILL.md` 增「批量模式」小节):复用一个 per-file 处理函数(单文件逻辑步骤 1-5),外层加「两遍式 + 汇总 + 幂等 + 日志」编排。skill 是会话内/无头两种模式的同一实现,差异只在 `--headless` 标志(无头:不提问、只第一遍、写日志)。
- **CLI 只读**:新增 `jspace inbox status [--json]`,读 filehub 正式路径或降级暂存区,列文件/计数。不做语义。
- **数据流**:`_inbox/` → (第一遍)确定性归位 + index + gbrain + 自检 → (第二遍)模糊清单人工过目 → 汇总 → 执行日志。人工调整:处理前 skip、处理后 撤销/重跑。

## 关键契约

### per-file 确定性判断(第一遍 vs 第二遍)
- **确定性** = 类型明确(pdf/ppt/txt/md/excel 之一)且 归属可判(项目或领域,文件名/内容给出)且 无查重冲突 且 命名可直接采用(`YYYY-MM-DD-语义名` 能从文件名/内容提取)。
- 任一不满足 → 进第二遍清单。
- 清单条目:文件路径 + 「不确定点」(归属?命名?查重冲突?类型?) + 建议选项(跳过/改归属/改命名/升版本/覆盖)。

### `.processing` 幂等
- 处理前在 `_inbox/` 写 `<file>.processing`(点文件,doctor 计数已跳过);成功 → 删除标记;失败 → 保留标记 + 在汇总里记原因。
- 重跑:有 `.processing` 标记的文件视为「已完成/失败待处理」——已完成的不重跑;失败项提示单独重试(可选 `--retry-failed`)。
- 中断续跑:扫 `_inbox/` 时排除已有 `.processing`(已完成)的文件。

### 执行日志(无头,固定路径)
- 路径:`<filehub>/.jspace-logs/inbox-batch.md`(filehub 根下隐藏目录,点目录不干扰 Obsidian/doctor)。未注册 filehub 时:工作台 `logs/inbox-batch.md` 或降级暂存区同级。
- 内容:时间、输入计数、成功/跳过/失败、每个文件结果(路径→目标),追加模式。
- 会话内第二遍在用户过目后也写一条摘要,便于下次会话检查(M3 失败可见性)。

### 机械校验
- 批量前后 `_inbox/` 文件计数对比(归位数 + 剩余数 = 原数,排除 `.processing`)。
- 确定性查重预检:`gbrain get assets/<项目|领域>/<语义名>` 已存在 → 该文件进第二遍(不擅自覆盖)。
- 召回自检:每份(或抽样)贴出实际 `gbrain query <关键词>` 输出。

### CLI `jspace inbox status`
- `jspace inbox status [--json]`
- 源:filehub 注册 → `<root>/_inbox/`;未注册 → 降级暂存区(工作台外 `../<workbench>-inbox/`,存在才列)。
- 输出:文件数 + 每项(文件名/大小/修改时间);空 → 提示无事可做。`--json` 机器可读(供无头预检)。
- 复用一个共享的「定位 inbox」helper(与 skill 的前置逻辑一致:读 `type: filehub` resource primary path,否则降级暂存区)。

## 兼容与迁移

- skill 变更后 `gen-assets.ts` 重新生成,工作台内已复制的 skill 下次 init 更新(现有工作台升级通道属 P6,不在本子任务)。
- 现有单文件路径(会话内逐份)保持可用;批量是新增模式,不破坏单文件。
- 无 gbrain 本体修改、无新 frontmatter 字段。

## 重要取舍

- **语义判断全在 AI**:CLI 不做分类/命名/查重——换来"无头/会话/单文件三种形态复用同一纪律",代价是无头必须有 key 且结果不可逐份人工审(故只跑确定性)。
- **`.processing` 标记而非事务**:无原子文件事务,靠「先归位再写页、失败即停单份」的单文件纪律控制一致性,可中断续跑。
- **日志在 filehub 内**:与资产同机、下次会话可查;`.jspace-logs/` 点目录避免污染 Obsidian 视图。

## 操作与回滚

- 撤销本次:把已归位文件移回 `_inbox/`(或用户指定 back 目录),删除对应 gbrain 页(或标注)、撤销 index 行。
- 重跑该份:对已归位文件重走单文件逻辑(修复语义,允许覆盖错页)。
- CLI 全部只读/本地文件操作,可逆。
